# Security Policy

SEES is a zero-knowledge encrypted vault. If you find a vulnerability — anything that could expose vault contents, break the encryption model, or compromise the server — please report it privately rather than opening a public issue.

## Reporting

Please use GitHub's private vulnerability reporting: go to the [Security tab](https://github.com/sees-im/sees/security) of this repo and click **Report a vulnerability**. Include:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- Any relevant logs or screenshots

We'll acknowledge reports within a few days. Please give us reasonable time to investigate and ship a fix before any public disclosure.

## Scope

In scope: the app at [sees.im](https://www.sees.im) and the code in this repository.

Out of scope: social engineering, denial-of-service testing against production, and issues that require physical access to a user's device.
